# tabbar

The button strip used by a tabwidget.

## At a glance

- **Kind:** `tabbar`
- **Category:** Layout
- **Children:** accepted, stacked by the container
- **Used in the shipped interface:** 0 times (available to mods, not used by the base game)

## When to use it

The button strip of a tab widget.

## Notes

Created by a `tabwidget`; declaring one directly is rarely useful.

## Common properties

All widgets also accept the [common properties](../common-properties.md); they are not repeated here.
